Leonida Nights — a GTA-style cover art maker: your photo + caption become a multi-panel poster with bold lettering and a sunset/neon grade, exported as PNG in 1080×1080, 1080×1350 and 1920×1080. Six panel layouts, five gradient-map grades, halftone title block, tilted snapshot strip, badge ribbon, per-panel drag/zoom, undo/redo. Static, offline, no build step. Fonts Anton & Pacifico under the SIL Open Font License (see app/fonts/OFL.txt).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
